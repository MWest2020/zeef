De pijplijn · één run, negen stages

Eén canoniek Document, negen stappen.

1Criteriazoekvraag → expliciete criteria
2Ingest + Normalize.eml/.msg + PDF → canoniek model
3Relatethreads + near-dupes
4Scope-filterregels eerst, LLM bij twijfel
5–6Embed → Retrieve → Rerankkandidaten + voor-trim tot top-K
7ScoreLLM scoort top-K + motivatie
8Selectinstelbare cutoff, recall-bias
9Exportxlsx · criteria · audit.jsonl

Twee LLM-momenten — begin (criteria) en eind (scoring) — de rest deterministisch. Amber = LLM-stap · groen = deterministisch.

Waar de AI oordeelt — en het uitlegt

Expliciete criteria, uitlegbare score.

Begin · criteria-articulatie

De LLM zet de zoekvraag om in een benoemde, leesbare set criteria — de relevantiedefinitie die een beoordelaar kan lezen en betwisten. Geëxporteerd als criteria.json.

Eind · scoring met motivatie

Elk kandidaat-document krijgt een relevantiescore die de top-X drijft, mét een motivatie van één zin. Hier bepaalt de AI wat de kern haalt — met onderbouwing. 

"stage": "score", "doc_id": "b7e2d4…", "llm_relevance": 0.91,
"motivatie": "scoort hoog: bevat publicatie- én geheimhoudingsclausule tussen de genoemde partijen"

De regel: LLM alleen bij een oordeel zonder mechanische grondwaarheid, en alleen waar een motivatie de verdedigbaarheid verhoogt. De rest blijft deterministisch.

Twee modi · één pijplijn · alleen de drivers verschillen

Soeverein of cloud — een vlag, geen code.

--profile sovereign

Sovereign

Volledig lokaal en air-gapped. Qwen3 via Ollama/vLLM, lokale embeddings + reranker. Geen netwerk. De primaire demo.

--profile cloud

Cloud

Topmodel voor maximale kwaliteit (Claude API + hosted embeddings/rerank). Vereist egress; alleen waar de omgeving dat toestaat.

--no-llm slaat alle generatieve stappen over — de maximaal-soevereine, air-gapped-veilige fallback.

De differentiator

De audit-trail is het product.

Eén append-only audit.jsonl: één event per stage-actie. Zowel de geselecteerde kern als de uitgesloten rest is er volledig uit te reconstrueren. 

"stage": "scope-filter", "doc_id": "a3f9c1…", "action": "excluded",
"reason": "calendar-invite (rule:R3)", "model": null, "where": "local"
"stage": "select", "doc_id": "b7e2d4…", "action": "selected",
"final_score": 0.81, "cutoff": "target=100 (knee@0.74)", "where": "local"

Per beslissing: welk model, waar het draaide (lokaal/cloud), en bij LLM-stappen de exacte prompt.

De selectie

Geen magisch getal — een bewuste keuze.

--top-n
harde telling
--threshold
score ≥ X
--target
adaptief, toont de "knie"

--target laat zien waar de score-knie ligt, zodat de gebruiker de afsnijding bewust kiest in plaats van een getal te slikken. De recall-bias verbreedt de snede bij twijfelgevallen — en is instelbaar.
